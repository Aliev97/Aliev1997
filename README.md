# Aliev97

Black-and-red Android starter app with a local Lua editor, local script saving, and a console.
Lua execution is sandboxed from Android/game memory: it does not attach to games, inject code,
read or modify other apps, or bypass anti-cheat.

## Build APK on GitHub
1. Upload all files and folders in this project to the root of your GitHub repository.
2. Open the **Actions** tab and enable workflows if GitHub asks.
3. Run **Build Aliev97 APK** with **Run workflow**, or push a commit to `main`.
4. Open the completed workflow run and download the `Aliev97-debug-apk` artifact.
